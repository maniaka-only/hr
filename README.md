# Курсова робота: Вебпортал відділу кадрів військової частини

Вебдодаток для автоматизації обліку особового складу військової частини (в/ч А3114, м. Полтава).

## Стек технологій
- Frontend: Angular 18 (Standalone компоненти, Signals), SCSS, Axios
- Backend: Node.js, Express, SQLite (sql.js)
- Авторизація: JWT, bcryptjs

## Швидкий запуск

1. Встановити залежності:
```bash
npm run install:all
```

2. Запустити клієнт і сервер одночасно:
```bash
npm run dev
```

Після запуску:
- Клієнтська частина: http://localhost:4200
- Бекенд API: http://localhost:3000/api

## Вхід у систему
- Логін: `admin`
- Пароль: `admin123`

## Деплой на Render
- Build Command: `npm run build`
- Start Command: `npm start`

## Структура репозиторію
- `client/` - клієнтська частина на Angular
- `server/` - серверна частина на Express та база даних SQLite
- `package.json` - кореневі скрипти для одночасного запуску через concurrently

## Основні можливості
- Головна сторінка зі слайдером та стрічкою з 10 наказів/новин частини
- Облік особового складу: перегляд, додавання, редагування, видалення, пошук, фільтрація за званням і підрозділом
- Перелік підрозділів військової частини з контактами командирів
- Формування та друк особової картки військовослужбовця
- Галерея з переглядом фотографій
- Сторінка контактів із картою розташування в Полтаві
